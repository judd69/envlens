X-ray a .env file before it ships.

EnvLens scans a dotenv file for leaked-looking secrets, credentials in URLs, placeholders, duplicates and production mistakes — and scores it, with a fix hint for every finding, before the file ever reaches a commit.

Scoring

Start at 100. Critical −20 (−25 for ENV01, ENV02, ENV11, ENV16), warning −5, info −1, floor 0. Grades: 90+ A, 75–89 B, 60–74 C, 40–59 D, below F. Verdict: any critical → FAIL, else any warning → NEEDS WORK, else CLEAN. Exit codes: 0 pass, 1 findings at/above --fail-on (default warning), 2 usage/file error.

Security

No output — text, JSON, or HTML — ever prints the value of a secret-named key or credentials inside a URL value. Secret values are replaced with a fixed mask; non-secret values may be shown. All example values in this project are fake.
